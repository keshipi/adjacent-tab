# Open New Tab Next to Current

新しいタブを、タブバーの末尾ではなく **現在開いているタブの隣（右）** に開く Chrome 拡張です。

## 動作

| 操作 | 既定の Chrome | この拡張を入れた場合 |
| --- | --- | --- |
| `Cmd/Ctrl + T`、「+」ボタン | タブバーの末尾 | アクティブタブの右隣 |
| アドレスバーで `Cmd/Alt + Enter`（新しいタブで開く） | タブバーの末尾・背面のまま | アクティブタブの右隣・新タブにフォーカス |
| `Cmd + クリック`、リンクを新しいタブで開く | 開き元の右隣・背面のまま | 位置は変更なし・新タブにフォーカス |
| セッション復元、バックグラウンドで開かれたタブ | 元の位置 | 変更なし |

- 連続してタブを開いた場合は、開いた順に右へ並びます。
- アクティブタブがピン留めタブのときは、ピン留め領域の直後に配置します。

## インストール（未パッケージ拡張として読み込む）

1. Chrome で `chrome://extensions` を開く
2. 右上の「デベロッパーモード」をオンにする
3. 「パッケージ化されていない拡張機能を読み込む」をクリックし、このディレクトリを選択する

必要な権限は `storage`（`chrome.storage.session` に直前のアクティブタブ ID を保持するため）だけです。
タブ移動に使う `chrome.tabs` の API は URL やタイトルを読まない範囲では権限が不要なので、
`tabs` 権限は宣言しておらず、閲覧中のページの内容や URL にはアクセスしません。

## 構成

- `manifest.json` — Manifest V3 の定義
- `background.js` — Service Worker。タブ作成を検知して `chrome.tabs.move` で移動する

## 実装メモ

### アクティブで作られるタブ（`Cmd + T`、「+」ボタン）

`chrome.tabs.onCreated` の時点では新しいタブが既にアクティブになっているため、
移動の起点となるタブを次の優先順で解決しています（`resolveAnchor`）。

1. `tab.openerTabId` — `Cmd+T` で作ったタブにも直前のアクティブタブが入っている
2. `chrome.tabs.onActivated` で追跡して `chrome.storage.session` に保存した tabId
   （Service Worker が停止しても復元できるようにするため）
3. `chrome.tabs.query({ active: true })` によるフォールバック

リンクを新しいタブで開いた場合は Chrome が既に開き元の隣へ配置するため、
「起点の index + 1 が新タブの index 以上なら何もしない」という判定で自動的に no-op になります。

### 非アクティブで作られるタブ（アドレスバーの `Cmd/Alt + Enter`、`Cmd + クリック`）

アドレスバーの `Cmd/Alt + Enter` はフォーカスを元のタブに残したまま新しいタブを開くため、
`onCreated` は `active: false` で届き、`onActivated` は発火しません。
`Cmd + クリック` で背面に開いたリンクタブも同じく非アクティブです。

どちらも最終的に前面へ出しますが、**作られる位置**が違うため移動の扱いは分かれます。

| | 作られる位置 |
| --- | --- |
| `Cmd + クリック`（背面リンク） | 開き元の直後（既にある子タブの後ろ） |
| アドレスバーの `Cmd/Alt + Enter` | タブバーの末尾 |

そこで非アクティブなタブは、`openerTabId` から Chrome 流の配置先
（`openerChildIndex` = 開き元の直後にある「開き元を `openerTabId` に持つタブ」の後ろ）を
計算し、そこへ移動します。背面リンクタブは既にその位置にいるので no-op になり、
末尾に置かれたタブだけが動きます。

移動先を「開き元の直隣」ではなく「既にある子タブの後ろ」にしているのは、
続けて複数のタブを開いたときに順序が逆に並ばないようにするためです。
`openerTabId` を持たない非アクティブタブ（セッション復元など）は対象外です。

移動の有無にかかわらず、`openerTabId` を持つ非アクティブタブは
`chrome.tabs.update({ active: true })` で前面に出します。
Chrome は `Cmd + クリック` と右クリックメニューの「リンクを新しいタブで開く」を
区別できる情報を渡さないため、後者も同様にフォーカスされます。
